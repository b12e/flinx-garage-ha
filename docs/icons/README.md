# Icons

[Material Design Icons](https://pictogrammers.com/library/mdi/) by Pictogrammers, the icon set Home Assistant uses, taken from [`@mdi/svg`](https://github.com/Templarian/MaterialDesign-SVG) 7.4.47 and licensed under the [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0). They are recoloured to Home Assistant blue (`#18BCF2`) so they read on GitHub's light and dark themes.
